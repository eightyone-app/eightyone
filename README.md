# EightyOne for developers and AI agents

Public docs and the `eightyone` agent skill, published from EightyOne's API repository: don't edit here, changes are overwritten. Read them at https://docs.eightyone.app.

## Install the skill in Claude Code

```
/plugin marketplace add eightyone-app/eightyone
/plugin install eightyone@eightyone
```

The plugin adds the skill and connects the EightyOne MCP server (`https://api.eightyone.app/mcp`): sign in with your EightyOne account when asked.

For Claude apps and other agents: [docs/downloads/eightyone-skill.zip](docs/downloads/eightyone-skill.zip), uploaded as a custom skill.

Version 2026.1025.16 (API 4.0.0).
